# doomsday
Just a funwebsite for myself and my marvel me.

## Pages
- `index.html`: countdown home page
- `reveal.html`: scroll-down 3D reveal (the camera moves from head to feet as you scroll; drag to rotate)
- `cast.html`: cast list

## Using your own 3D model
Put a `.glb` file at `models/figure.glb` and `reveal.html` uses it in place of the placeholder figure.
See `models/README.md`.
