# Your 3D model goes here

`reveal.html` looks for **`models/figure.glb`**.

- If the file is here, the page shows it (scaled and centred automatically).
- If it isn't, the page shows the built-in armored placeholder figure.

Only use a model you're allowed to put on a website: check the license on the
model's page (for example on Sketchfab, look for a license like CC-BY and credit
the creator on the site).
